# README: Project proj_PersonalProjects

## Overview

This repository serves as a launchpad for my personal projects across various domains including web development, chatbots, data engineering, hardware projects, and more. Rather than creating separate repositories for each small project, this central repository provides organization and structure for my creative endeavors.

## Repository Structure

- `dev/` - Main development folder containing individual project directories
  - Example: `dev/ir_turret/` - Arduino-based IR turret project

## How I Use This Repository

1. **Project Creation**: New projects start as subdirectories within the `dev/` folder
2. **Development**: Each project has its own isolated environment within the repository
3. **Documentation**: Each project maintains its own README and documentation
4. **Dependencies**: When appropriate, projects can share common libraries and resources

## Current Projects

- **IR Turret**: An Arduino-based infrared targeting system

## Getting Started

To start working on a new project:

1. Create a new directory in the `dev/` folder
2. Initialize with appropriate project structure
3. Document project details in a project-specific README
